## [未发布]

### 新增
- **🤝 Bot API 10.0 Bot-to-Bot 支持**: 可选的 Bot 间通讯模式
  - 新增 `ENABLE_BOT_TO_BOT` 开关，允许处理其他 bot 的消息
  - 新增 `ALLOWED_BOT_IDS` 白名单，防止死循环和滥用（强烈建议填写）
  - `BotToBotFilter` 中间件：默认丢弃 bot 消息，拦截自循环，强制执行白名单
  - 需在 @BotFather MiniApp 中开启 Bot-to-Bot Mode
- **🎬 Google Veo 3.0 支持**: 升级视频生成，具备原生音频功能
  - 原生音频生成，包含同步音效、对话和音乐
  - 增强视频质量，支持8秒720p生成
  - 支持负面提示词，排除不需要的元素
  - 快速生成模式，使用 `veo-3.0-fast-generate-preview`
- 增强文档与全面指南
- 高级部署配置
- 性能监控和分析集成

### 更改
- **Google Veo API**: 从 Veo 2.0 升级到 Veo 3.0 Fast
  - 修复 `personGeneration` 参数以兼容文本转视频
  - 移除 `durationSeconds` 参数（固定8秒视频）
  - 改进API请求结构和错误处理
- 改进错误处理和日志记录
- 增强安全实践文档

### 修复
- **AI SDK 兼容性**: 解决与最新AI SDK版本的冲突
- **Veo 3.0 参数**: 修复不支持参数的问题
- **请求处理**: 增强流式响应的 TypeScript 类型安全

## [2.0.0] - 2024-12-01

### 🎉 重大版本 - 完全重构

此版本代表了使用现代技术和增强功能的完整架构改革。

### 新增
- **AI SDK 集成**: 多个AI提供商的统一接口
- **增强的AI提供商支持**:
  - OpenAI (GPT-4, GPT-4 Turbo, GPT-3.5)
  - Anthropic Claude (Haiku, Sonnet, Opus)
  - Google Gemini (Pro, Flash)
  - xAI Grok
  - Mistral AI
  - Cohere
  - Google Vertex AI
- **函数调用系统**: 高级工具集成
- **模型上下文协议 (MCP)**: 可扩展工具生态系统
- **现代构建系统**: Vite + TypeScript 配置
- **Docker 支持**: 完整的容器化与多阶段构建
- **健康检查端点**: 系统监控和诊断
- **增强安全性**: 输入验证和速率限制
- **流式响应**: 实时AI响应流
- **多平台部署**: Docker, Vercel, Railway, Render, Koyeb
- **高级配置**: 基于环境的配置管理
- **错误恢复**: 强大的错误处理和重试机制
- **性能优化**: 缓存和响应优化

### 更改
- **破坏性更改**: 完全重写需要新的配置设置
- **TypeScript 迁移**: 完整的 TypeScript 代码库提高可靠性
- **模块化架构**: 基于插件的可扩展系统
- **配置格式**: 新的基于 TOML 的配置系统
- **数据库架构**: 增强数据模型以提高性能
- **API 响应**: 改进响应格式和错误消息

### 废弃
- 传统单文件部署 (兼容模式下仍支持)
- 旧环境变量格式 (提供迁移指南)

### 移除
- **破坏性更改**: 基于角色的系统 (替换为自定义命令)
- 传统AI提供商集成 (替换为AI SDK)
- 过时的部署方法

### 修复
- 长时间对话中的内存泄漏
- Token 计算精度
- 消息编辑可靠性
- 群聊权限处理
- 速率限制绕过漏洞

### 安全
- 增强输入清理
- 改进 Token 验证
- 安全环境变量处理
- 高级速率限制算法

## 迁移指南

### 从 v1.x 升级到 v2.0.0

这是一个有破坏性更改的主要版本。请按照我们的[迁移指南](MIGRATION.md)获取详细的升级说明。

**关键步骤:**
1. 备份当前配置
2. 将环境变量更新为新格式
3. 从角色系统迁移自定义命令
4. 在预发布环境中测试部署
5. 更新生产部署

### 从 v1.8.x 升级到 v1.9.0

插件系统引入需要:
1. 检查自定义修改的插件兼容性
2. 从官方插件注册表安装所需插件
3. 更新配置以启用插件系统
